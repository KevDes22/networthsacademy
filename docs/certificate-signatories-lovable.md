# Branded certificate

Apply [the certificate signatories SQL](certificate-signatories-lovable.sql) after the existing certification database setup. This adds a private field to the issued certificate and captures the assigned instructor's registered profile name when the certificate is created. Later edits to a profile or course assignment do not alter an issued certificate. The authorized certificate list returns the stored name to its owner. The Program Director printed on the template is Destiny Kevin.

Certificates issued before this change, and certificates for courses without an assigned instructor's registered name, display a blank instructor line. A historic instructor should only be added to a certificate when there is a verified record of who was assigned at issuance.

In a test course with an assigned instructor, issue a certificate, then open it from **Certificates** and use **Print or save PDF**. Confirm that the certificate is landscape, the PDF contains one page, and the issue date, ID and names match the issued record. Change the instructor profile name afterwards and confirm the old certificate displays the original name.
